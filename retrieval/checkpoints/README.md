# Retrieval checkpoints

Archive: `moffieldbench-checkpoints.tar.gz`.

Archive members use the prefix `retrieval/checkpoints/`, matching the paths to create under the repository root. See [checkpoint_archive.json](../../docs/checkpoint_archive.json) for every exact member path, size, and SHA-256.

Extract the archive into the repository root using the [installation instructions](../../docs/EXTERNAL_ASSETS.md#checkpoint-archive). The source tree itself does not include weight binaries. Original checkpoint bytes and embedded training metadata are unchanged.
